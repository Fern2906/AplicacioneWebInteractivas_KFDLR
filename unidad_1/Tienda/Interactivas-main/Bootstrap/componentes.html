1. Navbar (Barra de Navegación)

Componente responsive para crear menús de navegación.

.navbar - Clase base
.navbar-expand-{breakpoint} - Punto donde se expande
.navbar-toggler - Botón hamburguesa en móvil
.navbar-collapse - Contenido colapsable
.dropdown - Menú desplegable dentro de navbar

3. Modales (Ventanas Emergentes)

Ventanas emergentes que se superponen al contenido principal.

.modal - Contenedor principal
.modal-dialog - Diálogo del modal
.modal-header / .modal-body / .modal-footer - Estructura
data-bs-toggle="modal" - Activa el modal
data-bs-target="#id" - ID del modal a abrir

8. Alertas y Badges

Mensajes contextuales y etiquetas para información.

.alert - Clase base para alertas
.alert-dismissible - Añade botón de cierre
.badge - Etiqueta pequeña
.spinner-border / .spinner-grow - Indicadores de carga
Alertas
Alerta primaria - información general.
Alerta de éxito - operación completada.
Alerta de peligro - error crítico.
Alerta de advertencia - ten cuidado.
