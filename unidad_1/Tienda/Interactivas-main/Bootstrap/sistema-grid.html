El corazón de Bootstrap: Grid de 12 columnas con Flexbox

Contenedores Filas Columnas Responsive Anidación Offset Orden Layouts

1. Contenedores

Los contenedores son la base del grid. Centran el contenido y definen el ancho máximo.

.container - Ancho fijo que cambia en cada breakpoint
.container-fluid - Ancho del 100% siempre
.container-{breakpoint} - Ancho fijo hasta el breakpoint, luego 100%
Container fijo
.container - Ancho fijo y centrado
CÓDIGO
<div class="container">
  Contenido centrado con ancho máximo
</div>
Container fluid
.container-fluid - 100% de ancho
CÓDIGO
<div class="container-fluid">
  Contenido que ocupa todo el ancho
</div>
Container responsivo
.container-md - Fluido hasta md, luego fijo Redimensiona la ventana para ver el cambio
CÓDIGO
<div class="container-md">
  Fluido hasta md, fijo en md+
</div>

2. Filas

Las filas agrupan columnas y manejan el espaciado entre ellas.

.row - Clase base para crear una fila
.row-cols-* - Distribuye columnas automáticamente
.g-* - Espaciado entre columnas (gutter)
.gx-* - Espaciado horizontal
.gy-* - Espaciado vertical

3. Columnas

Las columnas contienen el contenido y se distribuyen en las 12 columnas del grid.

.col - Columna automática (distribuye equitativamente)
.col-{number} - Columna que ocupa {number} de 12
.col-auto - Columna que se ajusta al contenido

4. Columnas Responsivas

Las columnas pueden tener diferentes tamaños según el breakpoint.

.col-{breakpoint}-{number} - Columna responsiva
Breakpoints: sm (576px), md (768px), lg (992px), xl (1200px)
.d-none .d-md-block - Oculta/muestra según breakpoint
Grid responsivo
.col-12 .col-md-6 .col-lg-4
.col-12 .col-md-6 .col-lg-4
.col-12 .col-md-6 .col-lg-4

Móvil: 12 (100%) | Tablet: 6 (50%) | Escritorio: 4 (33.33%)
Redimensiona la ventana para ver los cambios

CÓDIGO
<div class="row">
  <div class="col-12 col-md-6 col-lg-4">
    12 en móvil, 6 en tablet, 4 en escritorio
  </div>
</div>
Ocultar/Mostrar según breakpoint
.d-block .d-sm-none (Solo móvil)
.d-none .d-sm-block .d-md-none (Solo tablet pequeña)
.d-none .d-md-block (Tablet y escritorio)

Redimensiona la ventana para ver los cambios

CÓDIGO
<!-- Visible solo en móvil -->
<div class="d-block d-sm-none">Móvil</div>
<!-- Visible en tablet y escritorio -->
<div class="d-none d-md-block">Tablet+</div>

5. Anidación (Nesting)

Puedes anidar filas dentro de columnas para crear layouts más complejos.

Cada fila anidada tiene su propio sistema de 12 columnas
El contenido de la columna padre limita el ancho de las columnas anidadas
Grid anidado
.col-8 (Columna principal)
.col-6 (Sub-columna)
.col-6 (Sub-columna)
.col-4 (Sidebar)
.col-12
.col-12
CÓDIGO
<div class="row">
  <div class="col-8">
    Columna principal
    <div class="row">
      <div class="col-6">Sub 1</div>
      <div class="col-6">Sub 2</div>
    </div>
  </div>
</div>

6. Offset (Desplazamiento)

El offset desplaza una columna a la derecha sin afectar a las demás.

.offset-{number} - Desplaza {number} columnas
.offset-{breakpoint}-{number} - Offset responsivo
Útil para centrar o crear espacios
Offset básico
.col-4
.col-4 .offset-4
.col-6 .offset-3 (Centrado)
.col-2
.col-4 .offset-2
.col-2 .offset-1
CÓDIGO
<!-- Centrar una columna -->
<div class="row">
  <div class="col-6 offset-3">Centrado</div>
</div>
Offset responsivo
.col-8 .offset-2 (móvil)
.col-md-6 .offset-md-3 (tablet+)

En móvil: 8 de 12 con offset 2 | En tablet+: 6 de 12 con offset 3

CÓDIGO
<div class="col-8 offset-2 col-md-6 offset-md-3">
  Offset responsivo
</div>

7. Orden de Columnas

Cambia el orden visual de las columnas sin modificar el HTML.

.order-{number} - Establece el orden (0-5)
.order-first - Orden -1 (primero)
.order-last - Orden 6 (último)
.order-{breakpoint}-{number} - Orden responsivo
Orden básico
3. order-last
1. order-first
2. order-2
CÓDIGO
<div class="row">
  <div class="col order-last">Último</div>
  <div class="col order-first">Primero</div>
  <div class="col order-2">Medio</div>
</div>
Orden responsivo
order-2 order-md-1
Móvil: 2° | Tablet+: 1°
order-1 order-md-2
Móvil: 1° | Tablet+: 2°
CÓDIGO
<div class="col order-2 order-md-1">
  Móvil: 2°, Tablet+: 1°
</div>

Actividad Práctica

Crea un layout de página completa usando el sistema de malla

Requisitos:
  • Header con logo a la izquierda y menú a la derecha
  • Sección Hero (imagen/llamada a la acción) de ancho completo
  • Grid de 3 tarjetas de servicios (responsive: 1, 2 o 3 columnas)
  • Sección de testimonios con 2 columnas
  • Footer con 4 columnas (contacto, enlaces, redes, copyright)
  • Usar gutters, offset y/o orden donde sea necesario
