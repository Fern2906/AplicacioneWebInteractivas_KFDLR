Que es jQuery?

Definicion, historia y caracteristicas principales

Definicion

jQuery es una biblioteca de JavaScript rapida, pequena y rica en funciones. Fue creada por John Resig en 2006 para simplificar la manipulacion del DOM, el manejo de eventos, las animaciones y las peticiones AJAX.

// jQuery en accion
$('#miElemento')
    .css('color', 'red')
    .html('Nuevo texto')
    .addClass('activo');
Caracteristicas clave
  • Selectores CSS: Usa selectores CSS para encontrar elementos
  • Encadenamiento: Los metodos retornan el objeto para encadenar
  • API unificada: Funciona igual en todos los navegadores
  • Iteracion implicita: Los metodos se aplican a todos los elementos
  • AJAX simplificado: Peticiones HTTP con una linea de codigo
  • Animaciones: Efectos visuales con metodos predefinidos
Filosofia

"Write less, do more" — Escribe menos, haz mas. jQuery reduce la cantidad de codigo necesario para tareas comunes.

JS puro: 10 lineas jQuery: 3 lineas
Framework o Biblioteca?

jQuery es una biblioteca (libreria), no un framework. No impone una arquitectura, solo proporciona utilidades.

Como funciona jQuery?

La funcion $, el objeto jQuery y el encadenamiento

La funcion $()

$ es el alias principal de jQuery. Es una factory function que crea un objeto jQuery a partir de un selector, elemento o HTML.

// Seleccionar por ID
$('#miId')

// Seleccionar por clase
$('.miClase')

// Seleccionar por etiqueta
$('div')

// Crear un elemento
$('<div>Hola</div>')

// Ejecutar cuando el DOM esta listo
$(function() {
  // Codigo seguro
});
$() siempre retorna un objeto jQuery, no elementos DOM

El objeto jQuery

El objeto jQuery es un array-like que contiene una coleccion de elementos DOM y todos los metodos disponibles.

// Crear objeto jQuery
const $elementos = $('div');

// Propiedades
$elementos.length // Numero de elementos
$elementos[0] // Primer elemento DOM
$elementos.get(0) // Primer elemento DOM
$elementos.eq(0) // Objeto jQuery con el primer elemento
El objeto jQuery NO es un array, pero se comporta como uno

Encadenamiento (Chaining)

Cada metodo jQuery retorna el mismo objeto, permitiendo encadenar multiples llamadas en una sola linea.

// Sin encadenamiento
const $elem = $('#id');
$elem.css('color', 'red');
$elem.html('Texto');

// Con encadenamiento
$('#id')
    .css('color', 'red')
    .html('Texto')
    .addClass('activo');
El encadenamiento funciona porque cada metodo retorna this

Iteracion implicita

Cuando aplicas un metodo a un objeto jQuery con multiples elementos, se aplica automaticamente a todos sin necesidad de un bucle.

// JS puro (necesitas un loop)
const elementos = document.querySelectorAll('.clase');
for (let i = 0; i < elementos.length; i++) {
  elementos[i].style.color = 'red';
}

// jQuery (iteracion implicita)
$('.clase').css('color', 'red'); // ✓ Se aplica a TODOS los elementos con .clase
La iteracion implicita reduce significativamente el codigo

Selectores de jQuery

La base de todo: como seleccionar elementos

Selectores basicos

Los selectores mas comunes

Selector Descripcion Ejemplo
$('#id') Por ID #header
$('.clase') Por clase .menu
$('etiqueta') Por etiqueta HTML div
$('*') Todos los elementos *
// Ejemplos de selectores basicos
$('#header') // Por ID
$('.menu-item') // Por clase
$('div') // Por etiqueta
$('*') // Todos los elementos

Selectores combinados

Combinaciones de selectores

Selector Descripcion Ejemplo
$('div.clase') Div con clase div.activo
$('div #id') ID dentro de div div #header
$('div > p') Hijo directo div > p
$('div p') Descendiente div p
$('div, p') Multiples div, p
// Ejemplos de selectores combinados
$('div.menu') // Div con clase menu
$('div > p') // P hijo directo de div
$('div p') // P dentro de div (cualquier nivel)
$('div, .clase') // Divs o elementos con clase
